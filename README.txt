SMART DESIGN - TIENDA DE DISEÑO Y DESARROLLO WEB
Tarea: Creación de una página web responsiva con Bootstrap, CSS y JavaScript (Rúbrica 6.1)

DESCRIPCIÓN
Sitio de una sola página para una tienda ficticia que vende landing pages y logos.
Se usa el logo de Smart Design como imagen principal. La página se adapta a
celular, tableta y computadora.

ARCHIVOS
  index.html   Estructura con HTML5 semántico: header, nav, main, section,
               article, aside, footer. Los comentarios al inicio explican las
               características de la estructura HTML5.
  styles.css   Estilos propios: paleta del logo, tipografías, layout y el aside
               con float: right (desde 992 px de ancho; en móvil ocupa todo el ancho).
  script.js    Prácticas de JavaScript: variables y tipos, arreglos y objetos,
               condicionales, bucles, funciones, alcance y clausuras.
               También maneja la tienda, el pedido y el formulario.
  images/      smart-design-logo.png (logo), smart-design-icon.png (ícono del menú),
               favicon.png.
  README.txt   Este archivo.

TECNOLOGÍAS
  HTML5, CSS3, JavaScript, Bootstrap 5.3 (por CDN, requiere internet).

CÓMO VERLO
  1. Descarga o clona la carpeta completa.
  2. Abre index.html en el navegador (o usa Live Server en Visual Studio Code).
  3. Presiona F12 y abre la pestaña "Console" para ver la salida de JavaScript.
  4. Ve a la sección "Laboratorio de JavaScript", cambia los valores y presiona
     "Ejecutar pruebas".

DÓNDE ESTÁ CADA CRITERIO DE LA RÚBRICA (script.js)
  Condicionales (if, else if, else) ... clasificarPrecio(), obtenerPorcentajeDescuento()
  Bucles for, for...of ................ ejecutarLaboratorio(), mostrarCatalogo()
  Bucles while, do...while ............ ejecutarLaboratorio(), sección 4
  Funciones ........................... formatearPrecio(), calcularDescuento(), entre otras
  Alcance (scope) ..................... demostrarAlcance() (global, función y bloque)
  Clausuras (closures) ................ crearContador(), crearPedido()
  Arreglos y objetos .................. arreglo "paquetes" y objeto "cliente"
  Pruebas y experimentación ........... consola del navegador y Laboratorio JS

NOTAS
  - Los precios y el correo de contacto son datos de ejemplo.
  - El formulario valida los campos pero no envía información a ningún servidor.
